# Real photos go here

Drop your own photos in this folder using these exact names. The site picks them up automatically;
if a photo is missing, the sample illustration from `assets/img/` is shown instead.

| What | File name | Suggested size |
|---|---|---|
| Product photos | `B2B-001.jpg` … `B2B-012.jpg` (the product code) | 900 × 1200 (3:4 portrait) |
| Category tiles | `cat-1.jpg` … `cat-6.jpg` (Gowns, Kandyan, Lehengas, Engagement, Sarees, Special) | 1200 × 1200 |
| Homepage slideshow | `slide-1.jpg` … `slide-4.jpg` | 1920 × 1080 (landscape) |

Tips: compress images (under ~300 KB each) so the site loads fast on phones.
